Выполняет наивное умножение матриц с использованием глобальной памяти GPU.

Каждый CUDA-поток вычисляет один элемент выходной матрицы C. Для вычисления скалярного произведения строки A и столбца B поток последовательно читает элементы из глобальной памяти.

Матрицы хранятся в row-major формате:

  • A имеет размер rows x N;
  • B имеет размер N x N;
  • C имеет размер rows x N.

Параметр rows позволяет обрабатывать как целую матрицу, так и отдельный блок строк при потоковом выполнении.

Аргументы
AУказатель на входную матрицу A в памяти GPU.
BУказатель на входную матрицу B в памяти GPU.
CУказатель на выходную матрицу C в памяти GPU.
NРазмерность квадратной матрицы B и число столбцов A.
rowsКоличество строк матриц A и C, обрабатываемых за один запуск.

Выполняет блочное умножение матриц с динамической shared memory.

Каждый CUDA-блок вычисляет тайл выходной матрицы. Тайлы входных матриц A и B поочерёдно загружаются из глобальной памяти в динамическую разделяемую память.

После синхронизации потоков блока выполняется вычисление частичных скалярных произведений. Граничные элементы, выходящие за пределы матриц, заполняются нулями.

Размер динамической shared memory задаётся при запуске ядра и должен быть равен двум тайлам размера TILE_SIZE x TILE_SIZE, умноженным на sizeof(BASE_TYPE).

Аргументы
AУказатель на входную матрицу A в памяти GPU.
BУказатель на входную матрицу B в памяти GPU.
CУказатель на выходную матрицу C в памяти GPU.
NРазмерность квадратной матрицы B и число столбцов A.
rowsКоличество обрабатываемых строк матриц A и C.

Проверяет корректность результата умножения матриц.

Сравнивает вычисленную матрицу с эталонной. Для сравнения используется комбинированный абсолютный и относительный допуск, значения которых зависят от BASE_TYPE.

Дополнительно проверяются размеры матриц и наличие конечных числовых значений. При обнаружении ошибки в консоль выводится информация о первом несовпадающем элементе.

Аргументы
resultПроверяемая матрица.
referenceЭталонная матрица.
NРазмерность квадратной матрицы.
Возвращает
true, если все элементы удовлетворяют заданному допуску; false в противном случае.
