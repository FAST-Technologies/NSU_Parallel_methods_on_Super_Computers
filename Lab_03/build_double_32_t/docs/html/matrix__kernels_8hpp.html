NРазмер стороны квадратной матрицы.
Заметки
После выполнения функция должна содержать N * N элементов.

Инициализирует матрицу случайными значениями.

Элементы генерируются в диапазоне [-5, 5]. Если размер переданного вектора не соответствует N * N, его размер изменяется до требуемого.

Генератор случайных чисел использует стандартную функцию rand(). Начальное состояние генератора задаётся вызывающей стороной.

Аргументы
matВектор, в котором хранится матрица.
NРазмерность квадратной матрицы.
Исключения
std::invalid_argumentЕсли N не является положительным числом.

bool verifyResult ( const std::vector< BASE_TYPE > &  result,
const std::vector< BASE_TYPE > &  reference,
int  N

Проверяет корректность результата умножения матриц.

Сравнивает вычисленную матрицу с эталонной и проверяет, укладываются ли различия элементов в заданные допуски.

Аргументы
resultРезультирующая матрица, полученная GPU-алгоритмом.
referenceЭталонная матрица для сравнения.
NРазмер стороны квадратных матриц.
Возвращает
true, если проверка всех элементов пройдена; false, если обнаружено отклонение за пределами допуска.

Сравнивает вычисленную матрицу с эталонной. Для сравнения используется единый абсолютный допуск, масштабируемый по RMS эталона и √N, значения которых зависят от BASE_TYPE.

Дополнительно проверяются размеры матриц и наличие конечных числовых значений. При обнаружении ошибки в консоль выводится информация о первом несовпадающем элементе.

Аргументы
resultПроверяемая матрица.
referenceЭталонная матрица.
NРазмерность квадратной матрицы.
Возвращает
true, если все элементы удовлетворяют заданному допуску; false в противном случае.

Проверяет результат по выборке элементов с независимым CPU-эталоном.

Эталонные значения выбранных элементов вычисляются на CPU с накоплением в double. Дополнительно проверяется отсутствие NaN и Inf во всём результирующем массиве. Дополнительно проверяются полные строки на границах чанков.
