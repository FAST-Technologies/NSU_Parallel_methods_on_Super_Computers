Макрос для проверки кода возврата функции CUDA Runtime API.

Выполняет переданный вызов CUDA-функции и проверяет полученный код ошибки. При возникновении ошибки выводит её описание, имя исходного файла и номер строки, после чего завершает выполнение программы.

Аргументы
callВызов функции CUDA Runtime API, возвращающей cudaError_t.
Заметки
Макрос предназначен для проверки синхронных кодов возврата. Для обнаружения ошибок асинхронного выполнения необходимо дополнительно использовать синхронизацию CUDA.
