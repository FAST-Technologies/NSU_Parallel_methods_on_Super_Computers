Типы

◆ BASE_TYPE

using BASE_TYPE = float

Базовый тип элементов матриц.

Тип определяется параметром MATRIX_USE_DOUBLE, передаваемым при конфигурации проекта через CMake:

  • MATRIX_USE_DOUBLE=0 — float;
  • MATRIX_USE_DOUBLE=1 — double.

Один и тот же тип используется CPU- и GPU-реализациями умножения матриц.

Размер стороны тайла CUDA-блока.

Определяет размеры двумерного блока потоков TILE_SIZE x TILE_SIZE и соответствующих тайлов shared memory.
