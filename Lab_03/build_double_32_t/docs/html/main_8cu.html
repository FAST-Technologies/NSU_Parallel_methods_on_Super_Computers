Точка входа лабораторной работы №3.

Выполняет серию экспериментов по сравнению алгоритмов умножения квадратных матриц и стратегий передачи данных между оперативной памятью CPU и памятью GPU.

Поддерживает полный бенчмарк и одиночный запуск с заданным N.

Для каждого размера матриц:

  1. Создаёт и инициализирует входные матрицы A и B.
  2. Вычисляет эталонный результат на CPU для небольших матриц.
  3. Выполняет прогревочные и измерительные запуски алгоритмов.
  4. Проверяет вычисленный результат.
  5. Вычисляет медианное и минимальное время выполнения.
  6. Сохраняет результаты экспериментов в CSV-файл.

Для N > 1024 полный CPU-эталон не вычисляется: используется verifySampled (выборочные элементы и полные строки на границах чанков стримов).

Возвращает
EXIT_SUCCESS при успешном завершении; EXIT_FAILURE при ошибке аргументов или CSV-файла.
