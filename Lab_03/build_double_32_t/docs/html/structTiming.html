Подробное описание

Временные характеристики одного запуска бенчмарка.

Все значения времени представлены в миллисекундах. 

     Для потоковых стратегий H2D, Kernel и D2H представляют
     максимальные длительности соответствующих операций
     среди CUDA streams, а не последовательные составляющие Total.

     Total измеряется отдельно и включает полную стоимость
     одного запуска: подготовку host-буферов, создание CUDA-ресурсов,
     выделение памяти, передачу данных, вычисления и освобождение
     ресурсов.

     Для Unified Managed автоматическая миграция страниц может
     учитываться во времени Kernel и Total

Определения стадий:

  • H2D: всё, что переносит входные данные на GPU, без cudaMalloc. Unified Managed: заполнение managed-буферов на CPU (миграция страниц происходит внутри ядра и попадает в Kernel). Unified Prefetch: заполнение + явный prefetch на GPU.
  • Total: от начала подготовки host-буферов (в т.ч. pinned) до освобождения GPU-ресурсов. cuBLAS-handle создаётся один раз и в Total не входит.
  • GFLOPS_Kernel для потоковых стратегий приближённый: Kernel там это максимум по streams, а чанки выполняются перекрываясь.
