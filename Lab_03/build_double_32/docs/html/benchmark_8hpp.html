Подробное описание

Интерфейс подсистемы бенчмаркинга CUDA.

Содержит перечисления алгоритмов и стратегий памяти, структуры результатов измерений, а также объявления функций для запуска экспериментов, обработки статистики и сохранения результатов в CSV-файл.

◆ MemoryStrategy

enum class MemoryStrategy
strong

Стратегия размещения и передачи данных между CPU и GPU.

Элементы перечислений
Pageable 

Обычная страничная память CPU и полная передача матриц.

Pinned 

Закреплённая страничная память CPU и полная передача матриц.

PageableStreams 

Обычная память CPU и передача частей матриц через CUDA streams.

PinnedStreams 

Закреплённая память CPU и передача частей матриц через CUDA streams.

UnifiedPrefetch 

Unified Memory с явным предварительным перемещением данных.

UnifiedManaged 

Unified Memory с автоматической миграцией страниц.

◆ isUnifiedPrefetchSupported()

bool isUnifiedPrefetchSupported ( )

Проверяет поддержку Unified Memory prefetch текущим GPU.

Проверка выполняется по свойству concurrentManagedAccess текущего CUDA-устройства.

Возвращает
true, если устройство поддерживает concurrent managed access; false в противном случае или при ошибке получения свойств.

Проверяет поддержку Unified Memory prefetch текущим GPU.

Свойство используется для определения возможности включения стратегии UnifiedPrefetch в набор экспериментов.

Возвращает
true, если concurrentManagedAccess ненулевой; false, если свойство отсутствует или сведения об устройстве получить не удалось.
