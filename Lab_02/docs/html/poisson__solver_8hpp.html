Подробное описание

Заголовочный файл для параллельного решателя уравнения Пуассона методом Якоби.

Содержит структуру данных, константы и прототипы функций для решения трехмерного уравнения Пуассона с использованием гибридной модели MPI + OpenMP. Реализована двумерная декомпозиция области, виртуальная топология, неблокирующие обмены (halo exchange) и перекрытие вычислений с коммуникациями.

Выполнение одного шага метода Якоби с перекрытием вычислений и обменов.

Реализует один итерационный шаг метода Якоби с использованием неблокирующих MPI-обменов для перекрытия коммуникаций и вычислений. Алгоритм:

  1. Упаковка данных и запуск асинхронных обменов (Non-blocking).
  2. Вычисление внутренних точек (перекрытие с коммуникациями).
  3. Ожидание завершения всех обменов.
  4. Распаковка полученных данных в ghost-слои.
  5. Вычисление граничных точек локальной подобласти.
    Аргументы
    phiТекущее приближение решения (включая ghost-слои).
    phi_newВектор для записи нового приближения.
    infoСтруктура с параметрами домена.
    NxГлобальный размер сетки по X.
    NyГлобальный размер сетки по Y.
    NzГлобальный размер сетки по Z.
    max_diffСсылка на переменную для записи локальной максимальной невязки.

◆ rhs_function()

double rhs_function ( double  x,
double  y,
double  z

Функция правой части уравнения Пуассона.

Уравнение: p = Δφ - a·φ = 6 - a*(x² + y² + z²). Для φ = x²+y²+z² лапласиан Δφ = 6. Δφ - Лапласиан, равный d²phi/dx² + d²phi/dy² + d²phi/dz².

Аргументы
xКоордината X.
yКоордината Y.
zКоордината Z.
Возвращает
Значение правой части ρ(x,y,z) = 6 - a·(x²+y²+z²).
